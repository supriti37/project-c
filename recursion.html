RECURSION Questions

1. Write a recursive function to calculate the sum of first n natural numbers.

Code
#include <stdio.h>

int sum(int n)
{
    if(n==1)
        return 1;

    return n + sum(n-1);
}

void main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d",&n);

    printf("Sum = %d",sum(n));
}
Output
Enter a number: 5
Sum = 15

2. Write a recursive function to calculate the factorial of a given number.

Code
#include <stdio.h>

int fact(int n)
{
    if(n==0 || n==1)
        return 1;

    return n * fact(n-1);
}

void main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d",&n);

    printf("Factorial = %d",fact(n));
}
Output
Enter a number: 5
Factorial = 120
