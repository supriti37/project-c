POINTER Questions

1. Write a C program to enter and print all elements of an array using a pointer.

Code
#include <stdio.h>

void main()
{
    int a[5], i;
    int *p;

    p = a;

    printf("Enter 5 elements:\n");

    for(i=0;i<5;i++)
    {
        scanf("%d",p+i);
    }

    printf("Array Elements are:\n");

    for(i=0;i<5;i++)
    {
        printf("%d ",*(p+i));
    }
}
Output
Enter 5 elements:
10
20
30
40
50

Array Elements are:
10 20 30 40 50

2. Write a program to swap two numbers using pointers.

Code
#include <stdio.h>

void main()
{
    int a,b,temp;
    int *p1,*p2;

    printf("Enter two numbers: ");
    scanf("%d%d",&a,&b);

    p1=&a;
    p2=&b;

    temp=*p1;
    *p1=*p2;
    *p2=temp;

    printf("After Swapping:\n");
    printf("A=%d\n",a);
    printf("B=%d",b);
}
Output
Enter two numbers: 10 20

After Swapping:
A=20
B=10

3. A pointer should point the array and through pointer we will fill all the locations of the array by asking the value from the user and print the array.

Code
#include <stdio.h>

void main()
{
    int a[5];
    int *p;
    int i;

    p=a;

    printf("Enter 5 values:\n");

    for(i=0;i<5;i++)
    {
        scanf("%d",(p+i));
    }

    printf("Array Elements:\n");

    for(i=0;i<5;i++)
    {
        printf("%d ",*(p+i));
    }
}
Output
Enter 5 values:

10
15
20
25
