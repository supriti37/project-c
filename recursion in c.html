RECURSION Questions

1. Write a program of recursion and display the output.

Code
#include <stdio.h>

void show(int n)
{
    if(n==0)
        return;

    printf("%d ",n);
    show(n-1);
}

void main()
{
    show(5);
}
Output
5 4 3 2 1

2. Write a program of recursion with global variable and display the output.

Code
#include <stdio.h>

int x=1;

void show()
{
    if(x>5)
        return;

    printf("%d ",x);
    x++;
    show();
}

void main()
{
    show();
}
Output
1 2 3 4 5

3. Write a program of recursion with local variable and display the output.

Code
#include <stdio.h>

void show(int x)
{
    if(x>5)
        return;

    printf("%d ",x);

    show(x+1);
}

void main()
{
    show(1);
}
Output
